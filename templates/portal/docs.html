Endpoints Catalog

1. Cricket Analytics Endpoints

Sub-30ms columnar calculations powered by DuckDB.

GET /api/v1/analytics/head-to-head

Calculates complete historical rivalry between two teams. Accepts franchise acronyms (e.g. CSK, MI, RCB).

Query Parameters: team1 (required), team2 (required)
GET /api/v1/analytics/orange-cap

Returns seasonal top run-scorer leaderboard with official wide-ball and super-over exclusion rules.

Query Parameters: season (e.g. 2024), limit (default: 10)
GET /api/v1/analytics/purple-cap

Returns seasonal top wicket-takers crediting only bowler-attributed dismissals and excluding super overs.

Query Parameters: season (e.g. 2024), limit (default: 10)
GET /api/v1/analytics/venue

Calculates stadium par score strictly on completed innings (≥ 19 overs or 10 wickets).

Query Parameters: venue (e.g. "Wankhede Stadium")

2. Match & Player Endpoints

Directory and granular scorecard lookups.

GET /api/v1/matches

Paginated list of match records filterable by season, team alias, venue, and city.

GET /api/v1/players

Searchable player directory supporting fuzzy name lookups (e.g. ?search=Kohli).

GET /api/v1/players/{player_id}

Full career batting aggregates (strike rate, 4s, 6s, average) and bowling aggregates (overs in strict decimal, economy, wickets).

3. System Probes

GET /health — Server status and latency stamping
GET /db-health — Real-time DuckDB active connection check
